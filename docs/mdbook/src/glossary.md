# 术语表

| 术语 | 含义 |
| --- | --- |
| 账单 | 一次货运交易的托运人、路线、车辆/货物、金额和收款状态记录 |
| 租户 | 数据隔离边界；用户拥有的数据必须带 tenant 条件 |
| 幂等键 | 标识一次业务命令的客户端键，重试需复用，同键不同内容冲突 |
| ETag / If-Match | 账单版本控制头，防止并发编辑覆盖 |
| OCR 任务 | 异步手写账单识别任务，成功后需人工复核再合并 |
| 责任链 | 按声明顺序执行的一组业务 Handler |
| Migrator | 仅执行 Flyway 数据库迁移的运行角色 |
| Soft delete | 标记删除时间而非物理删除，可审计并恢复 |
