# 阅读指南

本书介绍 Demeter 货运账单微信小程序及其 Java 后端，读者包括：

- **运营人员**：关注账单、收款、OCR 任务和生产观测。
- **开发新人**：关注目录、接口、责任链、数据边界和本地验证。
- **AI/自动化工具**：通过稳定的术语、状态和接口索引快速建立项目上下文。

文档中的“当前”以代码为准。小程序目前通过 `miniprogram/services/bill-service.js` 使用本地 Mock；后端接口和生产安全能力已经实现，但前后端尚未完成正式联调。OCR 识别供应商默认关闭，未配置时不会生成正式账单。

## 变更原则

新增功能时请同时更新本书对应章节，并说明影响的角色、接口、迁移和运维项。不要在文档中写入密钥、真实租户数据或生产 URL。
