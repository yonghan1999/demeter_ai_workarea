# 账单日常操作

## 查询与筛选

首页支持关键词搜索、状态、日期区间、托运人和标签筛选。关键词可匹配托运人、账单号、车辆/货物、起讫城市和标签；搜索页会提供托运人和路线建议，并保存最近 8 条搜索历史。

## 新建与编辑

手动录入需填写托运人、车辆/货物、日期、起点、终点和金额等字段。系统会校验格式，并通过托运人名称归一化提示可能重复的客户。后端编辑使用 `ETag`/`If-Match` 防止覆盖他人修改；遇到 409 时重新获取账单后合并再提交。

## 删除与恢复

列表支持单笔或当前筛选结果内批量软删除，并要求二次确认。误删通过“恢复”接口处理；禁止直接删除生产数据库记录。批量删除是事务性的，要么全部成功，要么不改变数据。

## 状态说明

后端账单状态为 `unpaid`（未收款）、`partially_paid`（部分收款）、`paid`（已收款）。小程序 Mock 还展示 `overdue` 样例，接入后端时以 API 枚举为准。
