# 收款与对账

收款操作写入支付流水，不覆盖历史记录。支持记录金额、方式、时间、参考号和备注；金额不能超过账单待收金额，未来时间最多允许 5 分钟时钟偏差。

## 幂等与撤销

创建收款、撤销收款都必须携带 `Idempotency-Key`。网络重试必须复用原键；同一键提交不同内容会返回 409。撤销通过 reversal 接口完成，状态变为 `reversed`，审计轨迹保留。

## 对账异常

服务在写入前校验支付流水汇总与账单已收金额一致；不一致时拒绝继续处理并提示联系支持。运营应记录账单 ID、支付 ID 和 `X-Request-Id`，由具备权限的人员执行受审计的修复流程。
