# 系统概览

Demeter 将货运业务拆为小程序端和后端服务：

| 部分 | 作用 | 当前状态 |
| --- | --- | --- |
| 微信小程序 | 账单录入、查询、筛选、收款操作入口、OCR 复核 | 通过服务层调用后端 API |
| Spring Boot API | 认证、账单、支付流水、OCR 任务和建议接口 | 已实现，需联调 |
| MySQL + Flyway | 持久化业务数据并版本化 schema | 生产由独立 migrator 执行 |
| Worker | 异步领取 OCR 任务并调用供应商 | 角色与边界已实现，供应商按配置启用 |
| Maintenance | 清理 OCR 原图、会话等维护任务 | 独立运行角色 |

## 核心业务流

1. 用户通过微信登录获得 Bearer Token。
2. 在首页查询或筛选账单；可手动新建、编辑、软删除和恢复。
3. 收款写入不可变支付流水，账单汇总状态随流水更新。
4. OCR 上传先创建异步任务；Worker 识别后，用户在小程序复核，并通过账单 API 持久化。
5. 每个业务操作经过 `BusinessChainExecutor`，并记录幂等、审计和指标。

## 重要边界

- 所有用户数据按租户隔离，查询和写入都必须带租户条件。
- 删除是软删除；支付撤销保留流水和审计轨迹。
- 生产运行时不执行 Flyway，启动只校验 schema 和角色就绪状态。
- 厂商 OCR 响应不落库，供应商错误映射为稳定错误类别。
